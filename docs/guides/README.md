# 이해를 돕는 자료

설계와 도구를 처음 보는 사람이 빠르게 감을 잡도록 만든 자료입니다. HTML 파일은 브라우저로 바로 열 수 있습니다(`open docs/guides/skillops-tools.html`). 인터넷에 연결돼 있으면 글꼴을 불러오고, 아니면 시스템 글꼴로 보입니다.

| 파일 | 내용 | 온라인 페이지 |
|---|---|---|
| `skillops-design.html` | SkillOps 설계도. 전체 구조, 해결책을 찾고 검증하는 파이프라인, 분업, 2일 일정 | https://claude.ai/artifact/EVw8gLuzz299a79Z6ghLtf |
| `skillops-tools.html` | SkillOps 도구 12개. 도구마다 하는 일, Agent가 도구를 부르는 순서도, C-1과 C-2가 맞물리는 곳 | https://claude.ai/artifact/CHyp8VpDeXnrhPYBkSEBtg |
| `../contracts/mcp-tools-input-output.md` | 도구별 입출력 JSON, 필드 설명, 읽고 쓰는 저장 공간. Notion에 표로 붙여 넣을 수 있습니다 | 없음 |

온라인 페이지는 작성자에게만 열려 있습니다. 보려면 작성자에게 공유를 요청하세요.

## 읽을 때 알아 둘 것

- `skillops-design.html`의 분업 부분은 예전 이름(W1~W5)을 씁니다. 지금 역할 이름(A, B, C-1, C-2, D)과 담당 폴더는 `docs/roles/`를 보세요.
- `skillops-tools.html`의 "1차안에서 아직 정하지 않은 것" 네 가지는 `docs/contracts/mcp-tools-input-output.md`(계약 5 v1 제안)에서 메웠습니다.
