## 범위와 확인 방법

- `service/`: Spring MVC, Security, MCP, snapshot 분석, workspace, Runner/Judge, 제안서·승인 저장.
- `order-agent/backend/`: 주문 API, Harness, 모델 결정, 업무 도구, Mock, 주문·snapshot·trace 저장, 저장 이벤트 전달.
- `skillops-agent/`: FastAPI, LangGraph, 증거 조회·원인 실험·후보 검증·제안서 저장, SQLite 실행 기록, prompts·scripts·tests.
- `frontend/` 및 `order-agent/frontend/`: API 클라이언트, 상태 저장, 화면, 초안·주문 복구, mock, 테스트.
- `skills/`, `order-agent/skills/`, `scenarios/`, Gradle·Python·npm·Compose·환경변수 예제, 기존 계약·설계·검증 문서.

소스의 선언과 호출, 테스트, 환경 설정을 대조했습니다. 생성물·의존성 소스·비밀 환경변수 파일은 분석 대상에서 제외했습니다. 외부 모델의 실제 유료 호출, 운영 주문 생성, 운영 데이터 초기화는 수행하지 않았습니다. 테스트 통과는 실제 모델을 포함한 전체 시스템 검증을 의미하지 않습니다.
