
## 1. 우리가 만드는 것 :SkillOps Agent

환경: 실무 환경에서 harness 구조를 가진 agent flow 작업 흐름에서 skills 를 사용하는 상황
상황: 만약 기존 업무 흐름이 변경되어 skills 를 변경하고 실행할 때 이에 따른 기존 agent 호출/입출력/의존성/설계 흐름이 변경된 사항을 정확히 이식받지 못할 수 있음. 
우리의 해결책: 이러한 상황에서 모든 agent들의 의존성, 구성을 파악하고 실제 skills 가 동작하도록 에러 최적 수정안을 제안하는 에이전트를 개발. 단순히 한 상황을 모면하기 위한 해결책 제시가 아닌 근본적인 전체 운영 구조 및 흐름을 고려한 강건한 해결책 제시하는 agent.
