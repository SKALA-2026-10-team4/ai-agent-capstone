# F1 · 출력 필드명 변경 (inventory-check)

데모 1순위. 1일차 18시 통합 1차의 대상.

## 담당자가 한 일 (물류팀)
`inventory-check/SKILL.md` 본문과 frontmatter 에서 출력 `inventory.available` 을 `inventory.예약가능수량` 으로 바꾸고,
`inventory.reserved` 는 "예약 가능 수량이 있으면 예약된 것으로 본다"며 **outputs 에서 삭제**했다.

## 의도 (담당자 말)
"재고 수량이 아니라 예약 가능 수량으로 판단하고 싶다. 예약 가능하면 곧 예약이다."

## 깨지는 곳
`payment` 의 inputs 에 `inventory.reserved` 가 있는데 공급하는 skill 이 없다 →
trace step `payment` status=error, `required input inventory.reserved not found`, final_status FAILED.

## 기대하는 수정안
| kind | 내용 | 기준 1~5 예상 |
|---|---|---|
| local (불합격) | inventory-check 를 원래대로 되돌림 | 1 ✓ 2 ✓ **3 ✗(의도 위반)** |
| **contract (추천)** | inventory-check outputs 에 `inventory.reserved` 복원 + 본문에 "예약가능수량 > 0 이면 reserved=true" 명시, payment 는 그대로 | 1 ✓ 2 ✓ 3 ✓ 4 ✓ footprint 1 |
| contract (대안) | payment 의 inputs 를 `inventory.예약가능수량` 으로 바꾸고 본문 조건을 "예약가능수량 ≥ 주문수량" 으로 | 1 ✓ 2 ✓ 3 ✓ 4 ✓ footprint 2 |
